# 論壇完整可用看板搜尋設計

日期：2026-10-18

狀態：對話設計已同意；本文件供規格審閱，尚未授權跳過實作計畫審閱。

## 目的與已確認需求

使用者希望避免 Mobile01 只有 16 個看板，也避免把全部看板直接列在首頁。單一論壇看板頁須提供搜尋介面，讓使用者找到推薦清單之外的看板、閱讀內容並加入收藏。

已同意的行為：

- 空白查詢顯示少量推薦看板；非空查詢搜尋完整可用目錄。
- 有遠端看板搜尋 API 時優先使用；否則允許下載目錄並定期更新後搜尋。
- 可用範圍包含公開看板、目前帳號有權存取的登入限定看板；排除交易、商城等不能以一般討論串閱讀的區域。
- 單一論壇頁搜尋僅查詢該論壇；既有收藏選板頁保留跨來源搜尋。
- 輸入延遲 300ms 後查詢、清除後回到推薦、支援分頁。
- 目錄有效期 24 小時，提供手動更新；更新失敗可用舊目錄並標示時間。登入、登出及切換帳號時重新取得符合目前權限的目錄。

## 採用方案與取捨

沿用 `getBoardPage` 作為共用入口，擴充目錄更新與結果資訊。Host 管介面、身分隔離及近期結果快取；來源負責網站搜尋、目錄解析、分類及可閱讀看板判定。

另外兩種方案不採用：增加平行 `searchBoards` 操作會讓分頁、錯誤及兩個選板入口重複；由 Host 抓取所有論壇目錄則會讓網站細節外洩至 Host，破壞既有來源隔離。

「完整」指來源支援的一般討論區在目前存取情境下可發現的看板，不保證網站未公開或刻意隱藏的看板。不能把 16 板精選或解析失敗後的部分目錄宣稱為完整。

## 介面與互動

```text
← Gamer 巴哈姆特                         Logout
[ 搜尋此論壇看板…                           × ]
推薦看板／「關鍵字」搜尋結果          [更新目錄]
（使用快取時）目錄更新於 YYYY/MM/DD HH:mm
┌─────────────────────────────────────────┐
│ 看板名稱                                │
│ 分類／說明                              │
│ 開啟網站                              ＋ │
└─────────────────────────────────────────┘
                  [載入更多]
```

- 搜尋欄在標題下且不隨結果清單捲走。手機與寬視窗均保留單一查詢及結果順序，鍵盤不得遮住必要操作。
- 空白與只有空白字元皆視為推薦查詢；至少一個非空白字元即可搜尋。Host 僅去除前後空白，不擅自改寫網站查詢語法。
- 新文字立即更新輸入值，300ms 後查第一頁。新查詢、分類變更、清除、來源或登入情境變更時取消舊請求並重置分頁；晚到回應不得覆蓋新結果。
- 推薦與查詢各有載入、成功、空結果及錯誤狀態。查詢成功為空顯示「找不到符合的看板」；失敗不得顯示成找不到。
- 下一頁失敗保留目前結果並提供重試。只在有下一頁 token 時顯示載入更多，載入中禁止重複送出。
- 保留卡片的開板、開啟網站與加入收藏操作。返回列表時保留該來源查詢與捲動位置；登入情境失效時清除受影響結果。
- 「更新目錄」對目錄來源強制重新取得目錄；對遠端搜尋來源重新查詢目前關鍵字。保留目前輸入並從第一頁開始。
- 既有概覽顯示的數量僅代表已載入推薦數，不能寫成全站看板總數。

## 協議契約

保留 `BoardQuery(text, categoryId)`、`BoardPageRequest`、`BoardPage` 與既有 IPC operation。採相容的 JSON 欄位擴充：

| 欄位 | 語意 |
| --- | --- |
| `BoardPageRequest.refresh`，預設 false | true 僅用於第一頁，繞過目錄有效期或近期結果；不授權無限抓取 |
| `BoardPage.catalogInfo`，可缺省 | 描述查詢來源、新鮮度與涵蓋程度；缺省表示舊版來源資訊未知 |
| `catalogInfo.mode` | `REMOTE_SEARCH` 或 `CATALOG` |
| `catalogInfo.updatedAtMillis` | 最近成功取得目前資料的時間；失敗回退不得改成現在 |
| `catalogInfo.isStale` | 已逾有效期，這次更新未成功而使用舊資料 |
| `catalogInfo.coverage` | `AVAILABLE`、`PARTIAL` 或 `UNKNOWN`；AVAILABLE 表示已完成目前可發現範圍的解析／搜尋流程 |

新欄位缺省時，Host 仍可搜尋但不得標示「完整」或虛構更新時間。新增 enum 未知值安全降為 UNKNOWN 語意；wire 解碼處理缺省與 null，不依賴 Gson 會呼叫 Kotlin 預設建構式的假設。

`pageSize` 預設 30，接受 1–100；超出回傳明確 invalid request。來源 API 固定頁面大小時，來源自行保存剩餘項目／偏移，不能 `take(pageSize)` 後直接跳網站下一頁而漏項。頁面 token 綁定正規化查詢、分類、目錄版本及登入情境；token 不含 credential，Host 不解析其內容。資料集或權限變更後，舊 token 回傳明確失效錯誤，Host 提示重新載入第一頁。

分類有值時必須同時符合分類與文字；來源無法提供該組合時明確回報不支援，不能忽略分類。分類本身不新增至單一論壇畫面，本次統一既有選板頁使用的契約。

欄位擴充不改 AIDL operation 編號。實作計畫須列出新舊 Host／extension 的 wire 測試與 extension-api 依賴更新。舊來源不理解 refresh 時仍可讀取，介面不得宣稱其已完成強制更新。完成本功能的三個官方來源需更新版本與契約測試。

## 來源取得策略與安全邊界

### Mobile01

由網站公開導覽與必要分類頁建立動態可閱讀 leaf board 目錄，保留精選清單僅作推薦排序種子。搜尋涵蓋動態目錄；可用的登入限定討論區須走既有 Host 管理的登入能力，若需增加該能力則納入來源 manifest／policy 的正式相容更新。

以可信網站目錄驗證、固定 HTTPS host、合法 board ID 與已核准網路政策取代固定 16 板門檻。收藏中合法的舊 board 不得只因不在推薦清單就被拒絕；網站實際回應仍須檢查權限、挑戰頁及討論串格式。不得把任意網址當看板或擴大成任意網路存取。

### Gamer

保留網站遠端關鍵字搜尋及推薦／分類 API。驗證遠端結果、分類組合與頁面大小；有更多結果時不能遺漏。有權限限制的看板依目前帳號情境處理，不因 `AuthenticatedSource` 身分就一律阻擋免登入公開搜尋。

### EYNY

延續網站目錄解析，擴充必要分類走訪與新鮮度。分類載入失敗時保留已取得的資料並標為 PARTIAL，提供重試，不宣稱完整。依目前登入情境取得可見目錄，禁止沿用前一帳號的受限結果。

### 共同限制

沒有遠端看板搜尋 API 的來源可用目錄搜尋，不為符合「實時」而每個字都重新爬全站。採既有 broker、timeout 與取消機制；單次目錄刷新額外限制總計 60 秒、最多 50 次 HTTP request、最多同時 2 次 request，無自動循環重試。達上限回報 PARTIAL 或明確失敗。不能將截斷資料標為 AVAILABLE；若真實網站需要更多請求，提出有證據的界限調整供審閱。

## 快取、權限與更新

- 完整目錄由來源持有；近期查詢結果由 Host 持有，兩者不混用。隔離程序沒有任意持久化權限，來源目錄首版使用記憶體快取，程序重啟即重新取得，不新增通用 extension 檔案能力。
- 目錄成功取得後 24 小時內重用；到期於下一次使用時更新，不安排背景常駐抓取。同一來源的目錄更新採 single flight，避免分類載入與搜尋同時觸發重複爬取。
- Host 近期快取維持有限筆數與容量；以 canonical Source identity、登入情境版本、查詢及分類隔離。情境版本是 Host 不含機密的失效識別，不是帳號名稱或 session token。
- 登入、登出、重新登入、session 過期、帳號切換，以及來源被停權／替換時取消請求、清除對應目錄和近期結果。即使 AuthState 同為 SignedIn，也須識別新 session；不能只觀察 enum 是否改變。
- 首版對需要登入來源的受限結果只保留在目前登入情境的記憶體，避免程序重啟後恢復過時受限資料。既有裸 Source ID 的持久化快取失效清除，不遷移成可信身分資料。
- 刷新失敗僅可回退同一身分、同一有效登入情境的資料。登入過期或登出時不可回退受限結果。
- 快取不是存取授權。開板、開網站及讀文仍走既有 source identity、opaque handle、網路政策及網站權限檢查。

## 錯誤與可觀察性

沿用既有 `SourceFailure`：分開 auth required／expired、challenge、rate limit、timeout、parser contract 與 site unavailable。部分目錄須有可讀提示與重試入口；無快取且完全無法取得目錄時回報失敗。

診斷記錄來源身分、操作、耗時、頁數、目錄狀態與錯誤碼，不記錄 cookie、token 或帳號資料。搜尋文字不寫入一般診斷日誌。

## 驗收

1. Mobile01 可搜到固定 16 板之外的至少兩個可閱讀 leaf board，搜尋結果可開板、開網站、加入收藏並於重新進入收藏後讀取。
2. Gamer 已知關鍵字可取得遠端結果；頁面大小 1、30、100 的串接結果不漏項、不重複；分類條件不得被靜默忽略。
3. EYNY 目錄內看板可搜尋；分類失敗呈現 PARTIAL，重試成功後恢復 AVAILABLE。
4. 單一論壇頁：推薦、文字搜尋、清除、空結果、首／後頁失敗及重試均可辨識；快速輸入及返回頁面無舊回應覆蓋。
5. 收藏選板頁跨來源搜尋沿用相同契約，各來源可獨立失敗／分頁，不被單一來源失敗阻斷。
6. 以可控時鐘驗證 24 小時有效期、手動更新、失敗回退原時間與 single flight；取消及 60 秒／50 request 邊界有效。
7. 登入前後、登出、過期與兩個帳號切換不出現前一情境的受限看板或快取；公開查詢不因免登入來源具有 auth capability 而被阻擋。
8. 新舊 wire 欄位缺省、null、未知值及往返測試通過；舊來源顯示未知涵蓋程度，不能假裝更新成功。
9. 不接受其他來源 board、惡意 host、非法 ID 或越權 token；推薦以外的合法 board 不被硬編碼精選清單拒絕。
10. Compose 驗證搜尋欄、清除、載入更多、收藏、鍵盤與寬視窗行為；先完成本機 fake／fixture 測試，再進行最小真站 smoke。登入限定部分未取得合法測試 session 時明確標為待驗證。
